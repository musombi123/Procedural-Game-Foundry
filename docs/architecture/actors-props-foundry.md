# Actors & Props Foundry

The actors/props stage accepts creator-authored descriptors and uses Blender's bundled Python API to build original meshes, basic armatures, collision metadata and interaction/behavior descriptors. Supported actor classes are NPC, enemy, animal and robot; supported prop classes are weapon, tool, vehicle, item, obstacle and container.

No model inference, asset downloads, image generation or paid API is used. Behavior and interaction fields are creator-authored metadata, not executable AI or a completed game-AI system. The stage is unlocked only after the creator approves the environment. Generated GLB and provenance manifest enter REVIEW and require explicit approval.

Actor count is limited to 12 and prop count to 40 per build. Blender execution must be validated on an installed supported Blender version before claiming runtime asset generation is verified.
